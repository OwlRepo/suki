NEW FEATURES TO ADD (APPROVED, GENERIC, REUSABLE)
────────────────────────────────────────
These features are required because they:
- Apply to MANY service businesses
- Reduce manual work
- Increase attendance and repeat visits
- Do NOT specialize Suki to one industry

You must plan them generically.

1) REAL MESSAGE SENDING
- SMS and Email sending (no drafting-only)
- Delivery status
- Retry + failure handling
- Consent + STOP opt-out enforcement
- Message history per customer
- AI must NEVER be required

2) AUTOMATIC APPOINTMENT REMINDERS
- Auto confirmation on booking
- Auto reminder at 24h (default ON)
- Optional 72h reminder (default OFF)
- Reschedule link included
- Extend existing “reminder sent” tracking into real behavior

3) MISSED APPOINTMENT RECOVERY
- Trigger when appointment status becomes “missed”
- Send polite follow-up automatically
- Include rebooking link
- Log outcome (rebooked / ignored)

4) POST-VISIT FOLLOW-UP
- Trigger after visit stamping (completed)
- Thank-you + rebook prompt
- Fixed delay (e.g. next day)
- Calm, transactional tone

5) WINBACK FOR INACTIVE CUSTOMERS
- Detect inactivity via existing last-visit data
- Default threshold (e.g. 60 days)
- ONE gentle reminder
- Strict frequency caps

6) LOYALTY UNLOCK NOTIFICATIONS
- Trigger when visit threshold reached
- Auto notify customer
- Simple “claim reward” CTA

7) SESSION / PACKAGE TRACKING (GENERIC)
- Optional prepaid session / package balance per customer
- Decrement balance on completed visit
- Show remaining sessions
- Trigger follow-up when package nearly complete or completed
- Must NOT be industry-specific (no “driving lessons” language)

8) STAFF ASSIGNMENT (LIGHTWEIGHT)
- Optional staff assignment on appointments
- Filter appointments by staff
- Include staff name in reminders (optional)
