- Buksan ang Customers para makita ang buong listahan at latest interactions.
- Pindutin ang Add customer para gumawa ng bagong customer record.
- I-save nang tama ang pangalan at mobile number para gumana ang appointments at messaging.
- Buksan ang customer profile para mag-update ng notes at details pagkatapos ng interaction.
- I-record ang bawat completed visit para tama ang Insights at retention metrics.
- Gamitin ang filters/search para mahanap ang repeat customers para sa follow-up.
- Kapag gagawa ng campaign, i-check dito ang tamang customer segment.
- Karaniwang mali: duplicate customer dahil iba-ibang format ng name.
- Recovery: mag-search muna bago mag-add, tapos i-update ang existing record.
- Karaniwang mali: nakakalimutang mag-log ng visit.
- Recovery: gamitin agad ang Dashboard shortcut pagkatapos ng bawat service.
