- Buksan ang Needs Attention mula sa dashboard navigation kapag may badge.
- I-review muna ang bawat task bago kontakin ang customer.
- Gamitin ang Open SMS app para buksan ang native SMS composer na may recipient at message body.
- Gamitin ang Copy message kung hindi napuno ng SMS app ang body.
- Kapag may duplicate-risk warning, i-check muna sa customer bago magpadala ulit.
- Gamitin lang ang Retry automatic SMS kapag confirmed ang delivery failure.
- Mark as contacted pagkatapos ma-send o matapos ng staff ang customer follow-up.
- Dismiss lang kapag hindi na kailangan kontakin ang customer.
- Karaniwang mali: automatic retry sa unknown-outcome message.
- Recovery: sundin ang warning, i-verify sa customer, saka magdesisyon kung manual na magpapadala.
