- Buksan ang Promos para gumawa ng discount o campaign messages.
- I-define muna ang goal (new visits, repeat visits, upsell).
- I-verify ang audience segment sa Customers bago mag-send.
- I-check ang Insights para tama ang timing ng campaign.
- Basahin ang message copy para malinaw at simple sa customers.
- Karaniwang mali: sobrang lawak ng audience na walang segmentation.
- Recovery: i-target ang segment base sa recent activity.
- Karaniwang mali: walang baseline metrics bago campaign.
- Recovery: i-record muna ang pre-campaign metrics sa Insights.
