- Buksan ang Settings at tingnan ang AI message credits at AI token credits.
- I-check ang SMS usage at remaining credits bago mag-send ng outreach.
- I-confirm ang reset date para malinaw kung kailan magre-refresh ang quota.
- Kung capped, i-guide ang user sa Help Center habang naghihintay ng reset o upgrade.
- Gamitin ang billing status para ipaliwanag ang upgrade path.
- Karaniwang mali: akala pareho lang ang tokens at messages limit.
- Recovery: ipaliwanag na hiwalay ang counters at pareho puwedeng ma-cap.
- Karaniwang mali: nalilito kung bakit gumagana pa ang AI kahit malapit na sa limit.
- Recovery: ipakita kung alin sa counters ang may natitira pa.
