- Open Customers to view the full customer list and latest interactions.
- Tap Add customer to create a new record with complete contact details.
- Save clear names and mobile numbers so appointment and messaging flows work reliably.
- Open a customer profile to update details, tags, and notes after each interaction.
- Record every completed visit so Insights and retention metrics stay accurate.
- Use filters/search to find repeat customers and prioritize follow-ups.
- When preparing campaigns, verify customer segments and contact channels from this page.
- Common mistake: adding duplicate names with different formats.
- Recovery: search first before adding, then merge or update the existing record.
- Common mistake: forgetting visit logs after service completion.
- Recovery: use Dashboard "record visit" shortcut immediately after each customer interaction.
