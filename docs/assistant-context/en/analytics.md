- Open Analytics when you need deeper breakdown than dashboard summaries.
- Review charts and grouped metrics to understand what drives changes.
- Validate date filters before comparing channels or periods.
- Use this page for detailed decision support after checking Insights.
- Track drops or spikes and connect them to recent promos or appointments.
- If charts look unusual, confirm source logs were recorded correctly.
- Common mistake: interpreting one chart without period context.
- Recovery: cross-check with Insights monthly totals.
- Common mistake: using Analytics for setup tasks.
- Recovery: return to operational pages (Customers/Appointments) for actions.
