- Open Promos to set up discount or campaign messaging.
- Confirm campaign goal first (new visits, repeat visits, upsell).
- Validate audience segment from Customers before sending.
- Check Insights so campaign timing matches business trends.
- Review message copy for plain and clear customer language.
- Common mistake: sending promos to broad lists without segmentation.
- Recovery: narrow audience by recent activity and intent.
- Common mistake: launching promo without performance baseline.
- Recovery: record pre-campaign metrics in Insights for comparison.
