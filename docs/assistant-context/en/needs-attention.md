- Open Needs Attention from the dashboard navigation when a badge appears.
- Review each task before contacting the customer.
- Use Open SMS app to open the phone's native composer with recipient and message body.
- Use Copy message when the SMS app does not prefill the body.
- If a duplicate-risk warning appears, check with the customer before sending again.
- Use Retry automatic SMS only when Tyvera shows the delivery failure was confirmed.
- Mark as contacted after staff sends or otherwise completes customer follow-up.
- Dismiss only when no customer contact is needed.
- Common mistake: retrying an unknown-outcome message automatically.
- Recovery: use the warning, verify with the customer, then decide whether to send manually.
