- Open Settings and review both AI message credits and AI token credits.
- Check SMS usage and remaining credits before sending outreach.
- Confirm reset date to explain when quotas refresh.
- If capped, direct users to Help Center workflows while waiting for reset or upgrade.
- Use billing status context to explain available upgrade path.
- Common mistake: assuming tokens and messages are the same limit.
- Recovery: explain they are separate counters and both can cap usage.
- Common mistake: confusion about why AI still works near one limit.
- Recovery: verify both counters and show which one is still available.
