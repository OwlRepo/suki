- Open Dashboard to see your current day priorities in plain cards.
- Read the "What this page is for" note first so you know why each card matters.
- Use the highlighted next-step button (for example, record a customer visit) to continue the primary workflow.
- Check metrics cards to quickly verify customer count, recent activity, and pending actions.
- If a card looks stale, refresh by completing the linked action (visit, appointment, promo) then return to Dashboard.
- If you are unsure where to go next, open Suki Assistant from this page and ask for the next action.
- Use this page as your daily starting point before going to Customers, Appointments, or Insights.
- Common mistake: skipping the next-step card and going directly to settings; finish operational tasks first.
- Recovery: if numbers look wrong, open Insights to verify period filters and business scope.
- Recovery: if action buttons are missing, confirm your role permissions and active workspace.
