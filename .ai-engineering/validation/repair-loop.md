# Bootstrap Repair Loop

When validation fails:

1.  Identify the exact problem.
2.  Identify affected markdown/config files.
3.  Explain why the issue exists.
4.  Apply the smallest possible fix.
5.  Do not modify application code.
6.  Re-run validation.

Repeat until:

PASS

or:

BLOCKED_HUMAN

BLOCKED_HUMAN is required when: - safety rules conflict - business
decisions are required - existing project instructions conflict - a
major workflow redesign is needed
