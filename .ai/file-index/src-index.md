# Source Index

| File Path | Purpose | Relationships | Usage Patterns |
|---|---|---|---|
| `apps/web/src/app/layout.tsx` | Web root layout and providers wiring | Uses `providers.tsx`, shared UI | Entry point for all web routes |
| `apps/web/src/app/(dashboard)/layout.tsx` | Dashboard shell composition | Uses `RequireSession` and navigation components | Shared protected frame for authenticated app pages |
| `apps/web/src/app/onboarding/layout.tsx` | Onboarding shell composition | Uses `RequireSession`, auth sync, workspace provider, and auth button | Shared protected frame for onboarding/setup pages |
| `apps/web/src/lib/plan-capabilities.ts` | Plan-to-web-visibility helper | Consumed by dashboard shell, analytics, settings, and AI UI surfaces | Maps current billing plan to AI visibility booleans without introducing a second provider flag |
| `apps/web/src/hooks/use-plan-capabilities.ts` | Client hook for plan-based AI visibility | Wraps billing status and plan-capabilities helper | Centralizes plan-aware hide/show logic for assistant, AI usage, analytics, and refine actions |
| `apps/web/src/proxy.ts` | Next middleware pass-through | Defers auth decisions to client/API session guard and backend API guards | Avoids rejecting API-origin session cookies at the web-origin middleware boundary |
| `apps/api/src/main.ts` | Nest application bootstrap | Loads `AppModule`, global pipe/filter, and auth bootstrap service | API process entry point including optional default-account initialization |
| `apps/api/src/app.module.ts` | Top-level API module composition | Imports domain modules and shared modules | Central dependency wiring |
| `apps/api/src/auth/clerk-auth.guard.ts` | First-party session guard | Used by protected API controllers | Resolves tenant context from canonical session cookie, temporary legacy cookie, or bearer token |
| `apps/api/src/billing/*` | Billing catalog, Lemon Squeezy integration, webhook ingestion, and status endpoints | Uses shared plan types, database subscription/webhook tables, and owner/tenant guards | Server-side variant resolution, checkout creation, webhook signature validation, and billing status orchestration with self-serve feature gating and free-cap fallback when disabled |
| `apps/api/src/test/deploy-workflow-governance.spec.ts` | Deploy workflow regression guard | Reads `.github/workflows/deploy.yml` from repo root | Verifies cold rebuild timeout settings, stale dev/prod Compose cleanup without volume deletion, and public web smoke checks for dev artifacts/localhost API URLs |
| `apps/api/src/intake/intake-booking.service.ts` | Intake slot availability, hold, and provider-aware OTP confirmation logic | Called by intake controller and uses DB schema plus OTP providers | Prevents slot conflicts, confirms booking intent via Twilio Verify or local Semaphore OTP hash verification, and records public-safe blocked-send audit outcomes when billing/provider sends are gated off |
| `apps/api/src/intake/otp/*` | Booking OTP provider abstraction, Twilio/Semaphore providers, and failover state | Used by `IntakeBookingService` and `IntakeModule` | Supports `OTP_PROVIDER_MODE`, organization-scoped persistent failover, Semaphore-generated Tyvera OTP hashes, and Twilio Verify fallback during migration |
| `apps/api/src/messaging/*` | Messaging provider, webhook, dispatch, and metering logic | Uses Semaphore/Twilio/Resend providers, metering tables, and automation policy | Explicit SMS provider selection, Semaphore outbound automation sends, secure Twilio webhook validation, TwiML inbound responses, segment-aware SMS credits, safe retry behavior, and provider delivery status updates |
| `apps/web/src/components/tyvera-assistant.tsx` | Global floating assistant panel entrypoint for dashboard surfaces | Integrated by adaptive app shell and powered by help-content + AI usage APIs | Guided chat + usage transparency UX for non-technical users, hidden entirely on free/starter plans |
| `apps/web/src/components/billing/*` | Billing presentation components | Used by `/pricing` and `/settings/billing` | Plan comparison, billing state banners, usage meters, add-on options, and checkout-sync UI |
| `packages/database/src/index.ts` | DB package public exports | Re-exports schema/db helpers | Imported by API services |
| `packages/types/src/index.ts` | Shared type and runtime contract exports | Imported by API/web/database packages | Includes Philippine mobile helpers plus shared billing plan/provider/status contracts used across API, web, and DB layers |
